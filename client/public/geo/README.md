# Geo data sources

- `admin1/*.json` — Natural Earth 10m admin-1 states/provinces (public domain, naturalearthdata.com)
- `countries-110m.json` — world-atlas TopoJSON derived from Natural Earth 110m (public domain)
- `countries.json` — country name/code index derived from mledoze/world-countries
- `cities.json` — cities with population >= 50k from GeoNames (download.geonames.org), licensed CC BY 4.0.
